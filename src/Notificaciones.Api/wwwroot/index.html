Cómo está construido

                    
Cuatro proyectos, dependencias apuntando siempre hacia el dominio.

                

            


            

                

                    01
                    
Domain

                    
Eventos inmutables y enumeraciones. Sin dependencias externas: define el contrato que todos los demás respetan.

                    NotificationEvent · NotificationLifecycleEvent
                

                

                    02
                    
Application

                    
Consumidor, motor de plantillas y contrato de envío. Orquesta el caso de uso sin conocer el transporte ni el proveedor.

                    NotificationConsumer · EmailTemplateEngine
                

                

                    03
                    
Infrastructure

                    
Adaptadores concretos: MailKit sobre SMTP, webhooks y la configuración de MassTransit con reintentos exponenciales.

                    SmtpEmailSender · DependencyInjection
                

                

                    04
                    
Api · Worker

                    
Dos hosts sobre el mismo núcleo: el gateway publica y proyecta telemetría, el worker consume y entrega.

                    Gateway REST · Background Service
